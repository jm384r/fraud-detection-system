SentinelAI

Real-Time Financial Fraud Detection & Audit Streaming System

Author: Joel Mukherjee

Architecture: Spring Boot + Python AI

Status: Fully Integrated & Tested

1. Executive Summary

SentinelAI is an end-to-end full-stack fraud intelligence platform engineered to intercept anomalous financial transactions in real time. Combining a high-throughput Java Spring Boot backend, an in-memory STOMP/WebSocket event broker, an ensemble Scikit-Learn Machine Learning pipeline, and Explainable AI (XAI) narrative generation via FastAPI, the platform delivers sub-40ms decision latency with proactive audit logging.

3. Core Modules & Implementation Details

A. Transaction Ingestion & Live WebSocket Broadcast:

TransactionController.java handles incoming payments via /api/transactions/process. Evaluated results are asynchronously dispatched to active dashboard clients over /topic/transactions using SimpMessagingTemplate.

B. Entity Onboarding & Adaptive Baselining:

AuthController.java securely provisions account entities, recording base coordinates (e.g., Raipur) and customized daily limits (e.g., ₹50,000) for baseline heuristic profiling.

C. Real-Time Responsive Overview Dashboard:

index.html maintains a persistent SockJS connection. New transaction evaluations are prepended to the top of the audit table with zero page reloads while simultaneously updating KPI counters.

D. Attack Simulator with Heuristic Presets:

simulator.html supports one-click verification of legitimate local payments, impossible velocity attacks (>750 km/h via Haversine), and high-value threshold spikes.
